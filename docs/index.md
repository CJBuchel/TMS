# TMS

Tournament management for FIRST LEGO League Challenge events: robot game, queueing, judging, deliberation and printables, run from one Rust server with a web client that installs on iPads.

- [Running TMS](ops.md): the release folder, services, network, backups, the day itself
- [Who does what](guides/roles.md) and [setting up tablets](guides/tablets.md)
- [Adding a season](seasons.md)
- [REST API](api/rest.md)
- [Live feed (WebSocket)](api/websocket.md)
- [Development](development.md)

The full design and phase plan is `PLAN.md` at the repository root.
